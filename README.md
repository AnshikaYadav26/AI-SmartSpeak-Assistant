# SpeakSmart AI – Speech Improvement Assistant

An AI-powered speech improvement assistant that analyzes speech recordings to provide feedback on fluency, confidence, speaking speed, and filler words. Features include speech-to-text conversion, performance scoring, personalized suggestions, interactive dashboards, and session history tracking.

## Features

- Speech recording using a microphone
- Speech-to-text conversion
- Speaking speed (WPM) calculation
- Filler word detection
- Fluency scoring
- Confidence scoring
- Personalized improvement suggestions
- Interactive performance dashboard
- Speech performance charts and analytics
- Session history and progress tracking

## Technologies Used

- HTML
- CSS
- JavaScript
- Web Speech API
- LocalStorage
- Chart.js

## System Workflow

```text
User Speech
     ↓
Speech Recording
     ↓
Speech-to-Text Conversion
     ↓
Speech Analysis
     ↓
Performance Scoring
     ↓
Feedback & Suggestions
     ↓
Dashboard & History
```

## Modules

### Dashboard Module
Displays speech performance metrics, charts, and analytics.

### Recording Module
Captures the user's speech through the microphone and converts it into text.

### Analysis Module
Analyzes the recorded speech and calculates WPM, filler words, fluency, and confidence scores.

### History Module
Stores previous speech sessions and tracks performance improvement over time.

## How to Run

1. Open the project in a web browser.
2. Allow microphone access when prompted.
3. Navigate to the **Record** section.
4. Start recording your speech.
5. Stop the recording and analyze the speech.
6. View your performance metrics, feedback, and suggestions on the dashboard.

The system provides:

- Speech-to-text conversion
- Speech analysis

- Speaking speed measurement
- Filler word detection
- Personalized feedback
- Performance tracking
